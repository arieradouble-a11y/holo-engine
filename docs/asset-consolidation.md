# Консолидация ассетов, 12 октября 2026

Источник: локальный Mediashtabzkh. Исходные файлы в Медиаштабе не изменялись.
Сайт не публиковался. На момент начала работ `main` holo-engine совпадал с
GitHub (`5de87fce0cc974e347257614bc19def4359834db`).

Основной движок уже был закоммичен, но `.gitignore` исключал сборки и GLB-детали.
Исключения сужены до 13 используемых наборов деталей, трех донорских узлов,
миниатюр каталога и готового музейного снимка. Экспериментальные модели,
видеофайлы, зависимости и временные сборки по-прежнему остаются локальными.

Перенесены 60 голограмм с актуальными дополнениями темы и отдельный
пилот 14 детализированных домов. Архивные материалы реконструкций сохранены
с описаниями источников; это учебные реконструкции, их ограничения записаны
в исходных README и конфигурациях. Не все чертежи относятся к Тюмени.

Изменения для переносимости:

- Абсолютные импорты Three.js/puppeteer пилота заменены относительными путями
  к зависимостям `engine/`; путь Chrome можно задать переменной `CHROME`.
- Добавлены команды пересборки, локальный сервер примеров.
- Сборщик каталога создает выходную директорию, если ее еще нет.
- В `mediashtab-import.json` сохранены хеши оригиналов; после адаптации путей
  и пересборки некоторые файлы пилота закономерно отличаются от этих хешей.

Обновление снимка из другого checkout:

```powershell
node engine/tools/collect-mediashtab.mjs C:/path/to/mediashtabgkh
node engine/tools/portable-house-detail.mjs
npm run build:houses
```

Импорт намеренно не переносит загрузчики FTP, учетные данные, базы жителей,
серверный код или материалы остальных разделов сайта.
