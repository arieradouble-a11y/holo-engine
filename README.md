# Holo Engine — движок и библиотека голограмм ЖКХ

В одном репозитории собраны движок, входные GLB-детали коммунальной техники,
60 готовых музейных голограмм и отдельная галерея 14 детализированных жилых домов.
Сборка 12 октября 2026 года переносит наработки из Медиаштаба в репозиторий движка.

## Запуск

Нужен Node.js 22 или новее. Из корня репозитория:

```powershell
npm --prefix engine ci
npm run preview
```

- Музей: http://127.0.0.1:8778/golomuzey/
- Детализированные дома: http://127.0.0.1:8778/houses/
- Сравнение исходного дома 121 и пилота: http://127.0.0.1:8778/pilot/
- Словарь: http://127.0.0.1:8778/metavselennaya/#glossary

Голограммы также можно открывать отдельными HTML-файлами без сервера.
Словарь и модульные дополнения музея требуют HTTP. Полная энциклопедия,
редакция, сервер сайта и публикация остаются в Mediashtabzkh.

## Пересборка и проверки

```powershell
npm run build:catalog
npm run build:houses
npm run test:glossary
# Проверка сама запускает сервер на 8879; путь Chrome можно задать через CHROME:
node engine/tools/check-asset-release.mjs
```

Каноническая сборка 60 объектов попадает в `engine/out/catalog/` (адрес `/catalog/`).
Все 13 наборов GLB-деталей техники и миниатюры теперь входят в Git.
Пересборка домов обновляет только `examples/house-detail/`: отдельный пилот
с дополнительной геометрией и профилями качества не подменяет основной движок.

## Что находится в репозитории

| Путь | Содержимое |
|---|---|
| `engine/` | Канонический движок, конфигурации, генераторы и инструменты |
| `*-parts/`, `avtokran-parts2/` | Отобранные входные GLB для 13 музейных машин |
| `catalog-thumbs/` | Миниатюры для воспроизводимой сборки каталога |
| `examples/mediashtab/` | Снимок 60 голограмм, каталога, словаря и музейных стилей |
| `examples/house-detail/` | 14 домов, исходники, конфигурации, сборка и исторические материалы QA |
| `assets/housing-evidence/` | Чертежи, источники и пояснения к реконструкциям домов |
| `docs/mediashtab-import.json` | Перечень импортированных файлов и хеши оригиналов |
| `reports/` | Новые проверки этой консолидации |

Документация движка: [engine/README.md](engine/README.md).
Подробности переноса: [docs/asset-consolidation.md](docs/asset-consolidation.md).
Результаты старых прогонов в `examples/**/qa/` относятся к датам исходных работ.
Проверки SwiftShader подтверждают загрузку и поведение, но не FPS на реальном телефоне.
